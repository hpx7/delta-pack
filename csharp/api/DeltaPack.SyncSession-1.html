Class SyncSession<T>

Namespace

A stateful handle over a one-way state-sync session between two endpoints.

Each endpoint holds a SyncSession<T> representing the current shared view of the peer's state. The sender calls Encode(T) to produce bytes; the receiver calls Decode(byte[]) to apply them. Both sides converge on the same view as long as messages are delivered in order.

The class handles the "first call is full encode, subsequent are diffs" distinction internally. It also ensures the sender's view always matches what the peer reconstructs — even when the user's state object has been mutated or reordered in ways that would break a raw EncodeDiff call.

Prefer the generated CreateSyncSession() factory on each schema type: 

var session = GameState.CreateSyncSession();

The delegate-taking constructor below is the lower-level entry point — useful when you need to pass custom encode/decode/clone callbacks, but most callers should go through the factory.
