Interface IDirtyTracked

Namespace
DeltaPack
Assembly
DeltaPack.dll

Base contract for types that participate in delta-pack's dirty-tracking graph. Exposes parent-chain wiring (for propagation) and a snapshot-version slot (used at diff-encode time as the baseline). Implementers fall into two narrower categories — ITrackedObject for [DeltaPackTracked] classes (slot-keyed dirty storage) and ITrackedContainer for TrackedList<T> / TrackedOrderedDict<TKey, TValue> (key-keyed dirty storage).
