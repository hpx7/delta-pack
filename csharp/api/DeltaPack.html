DeltaPackRangeAttribute

Specifies min/max bounds for integer encoding. Bounded integers are encoded more efficiently when values are constrained.

DeltaPackTrackedAttribute

Opt-in change tracking for a DeltaPackAttribute class. Mutations on serialized properties are recorded so EncodeDiff can skip equality comparisons on unchanged fields, producing identical bytes at lower cost.

Requires the consuming project to set <LangVersion>13</LangVersion>: tracked serialized properties must be declared partial so the source generator can emit dirty-marking setters. Collection-typed properties should use TrackedList<T> / TrackedOrderedDict<TKey, TValue> so mutations inside the collection are also recorded.

SyncSession<T>

A stateful handle over a one-way state-sync session between two endpoints.

Each endpoint holds a SyncSession<T> representing the current shared view of the peer's state. The sender calls Encode(T) to produce bytes; the receiver calls Decode(byte[]) to apply them. Both sides converge on the same view as long as messages are delivered in order.

The class handles the "first call is full encode, subsequent are diffs" distinction internally. It also ensures the sender's view always matches what the peer reconstructs — even when the user's state object has been mutated or reordered in ways that would break a raw EncodeDiff call.

Prefer the generated CreateSyncSession() factory on each schema type: 

var session = GameState.CreateSyncSession();

The delegate-taking constructor below is the lower-level entry point — useful when you need to pass custom encode/decode/clone callbacks, but most callers should go through the factory.

TrackedList<T>

A List<T>-compatible list that records per-index version numbers on every mutation. Intended as a drop-in replacement for List<T> on serialized properties of DeltaPackTrackedAttribute classes so EncodeDiff can skip unchanged-index comparisons.

TrackedOrderedDict<TKey, TValue>

An insertion-order-preserving dictionary that records per-key version numbers on mutations. Intended as a drop-in replacement for OrderedDict<TKey, TValue> on serialized properties of DeltaPackTrackedAttribute classes. Tracks three separate maps: updated keys (DirtyKeys), newly inserted keys (CreatedKeys), and removed keys (DeletedKeys) so EncodeDiff can emit only actual changes since the last snapshot.

Interfaces

IDirtyTracked

Base contract for types that participate in delta-pack's dirty-tracking graph. Exposes parent-chain wiring (for propagation) and a snapshot-version slot (used at diff-encode time as the baseline). Implementers fall into two narrower categories — ITrackedObject for [DeltaPackTracked] classes (slot-keyed dirty storage) and ITrackedContainer for TrackedList<T> / TrackedOrderedDict<TKey, TValue> (key-keyed dirty storage).

ITrackedContainer

Implemented by tracked container types (TrackedList<T>, TrackedOrderedDict<TKey, TValue>) whose dirty storage is keyed by user-supplied index / key rather than by a compile-time slot.

ITrackedObject

Implemented by [DeltaPackTracked] classes. Dirty storage is slot-based — one long per declared field, indexed by the compile-time slot assigned by the source generator. Avoids the string-hash and dictionary-lookup cost of a keyed scheme.
