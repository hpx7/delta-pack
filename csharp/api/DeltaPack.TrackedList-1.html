Class TrackedList<T>

Namespace
DeltaPack
Assembly
DeltaPack.dll

A List<T>-compatible list that records per-index version numbers on every mutation. Intended as a drop-in replacement for List<T> on serialized properties of DeltaPackTrackedAttribute classes so EncodeDiff can skip unchanged-index comparisons.

public sealed class TrackedList<T> : IList<T>, ICollection<T>, IReadOnlyList<T>, IReadOnlyCollection<T>, IEnumerable<T>, IEnumerable, ITrackedContainer, IDirtyTracked
