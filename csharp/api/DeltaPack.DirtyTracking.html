PropagateToParent(IDirtyTracked, long)

Walks up the parent chain, invoking the appropriate MarkDirty overload at each hop. Object parents use the slot-based MarkDirty(int, long) (read from the child's ParentSlot); container parents use the keyed MarkDirty(object, long) (from ParentKey). Stops as soon as a parent reports its entry was already at or past version.

Registers snapshot as a baseline against source's tracking state. Recursively sets SnapshotVersion on snapshot (and nested tracked containers) to the current global version, and prunes deleted-key tombstones from source that are older than any surviving snapshot.
